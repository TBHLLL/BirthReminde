# 生日提醒 (BirthReminde)

一个 ClassIsland 插件，用于显示当天或即将到来的生日提醒。

## 功能特点

- 🎂 **生日提醒**：自动检测并显示当天或7天内即将到来的生日
- ⚡ **实时更新**：每分钟自动刷新，确保信息准确
- 📝 **生日管理**：支持添加、删除生日信息
- 🎨 **自定义样式**：可调整字体大小、颜色和紧凑模式

## 使用方法

1. 在插件设置页面添加生日信息（姓名和日期）
2. 主界面组件会自动显示最近的生日提醒
3. 当天生日会显示年龄信息

## 显示说明

- **今天生日**：显示"今天生日！X岁"
- **明天生日**：显示"明天生日"
- **其他情况**：显示"还有X天"
